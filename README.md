# Python Learning

Um repositório pessoal dedicado ao aprendizado de Python, documentando aulas, exemplos, exercícios, experimentos e projetos práticos ao longo de uma jornada de estudos.

> Status: Rascunho inicial (Initial Draft)

## Objetivos de aprendizado

- Acompanhar, de forma organizada, a playlist completa de Python.
- Registrar anotações e conceitos de cada aula.
- Guardar exemplos acompanhados durante as aulas.
- Resolver exercícios de forma independente.
- Desenvolver desafios e projetos práticos.
- Documentar descobertas técnicas e o progresso geral.

## Playlist de referência

https://youtube.com/playlist?list=PLIbmlYZ19yU4tmcsZnvBS038l-DDlNiQg

A playlist contém 129 vídeos, organizados aqui em 129 pastas numeradas de `001` a `129`.

## Organização do repositório

```text
python-learning/
├── aulas/           # Uma pasta por aula (001 a 129)
├── desafios/        # Desafios por nível: iniciante, intermediario, livre
├── projetos/        # Projetos independentes
├── referencias/     # Links e documentação úteis
├── PROGRESS.md      # Acompanhamento de progresso
├── requirements.txt # Dependências (quando necessárias)
└── .gitignore
```

Cada pasta de aula contém:

- `README.md`: anotações, conceitos, dificuldades e checklist de exercícios.
- `exemplos/`: código acompanhado durante a aula.
- `exercicios/`: soluções dos exercícios.
- `experimentos/`: testes pessoais e rascunhos.

## Fluxo de trabalho por aula

1. Atualizar o status da aula no `README.md` da pasta correspondente.
2. Registrar os conceitos apresentados e as dúvidas.
3. Salvar os exemplos em `exemplos/`.
4. Resolver os exercícios em `exercicios/` e marcar o checklist.
5. Registrar experimentos em `experimentos/`.
6. Marcar a aula como concluída no `PROGRESS.md`.

## Convenções

- Pastas em minúsculas e sem acentos.
- Aulas numeradas com três dígitos (`001`, `002`, ...).
- Arquivos Python com nomes descritivos em `snake_case`.
- Documentação em Markdown, em português.
- Identificadores de código em inglês, sempre que possível.
